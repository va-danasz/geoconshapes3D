# GeoConShapes 3D

Required packages:
```bash
pip install trimesh pyvista python-fcl scipy
```

## Installation

1. Clone the repository.
2. Install the dependencies listed above.
3. Adjust settings in `config.py` (image size, sample count, thresholds, etc.).

## Assets
